This roadmap will be filled in after:

## Definition of Done for V2

Version 2 will be considered complete when:

- [ ] All Sprint 1 items are shipped
- [ ] All Sprint 2 items are shipped (or explicitly deferred)
- [ ] New features have automated tests
- [ ] Updated README reflects new features
- [ ] Deployed to production and tested on mobile
- [ ] Committed to GitHub with clean history

---

## How to update this document

When you have feedback:
1. Fill in `V2_FEEDBACK.md` with observations
2. Prioritize items as MUST-HAVE / NICE-TO-HAVE / SKIP
3. Move MUST-HAVE items into Sprint 1
4. Move NICE-TO-HAVE items into Sprint 2
5. Move SKIP items into Sprint 3 (or drop them)
6. Commit the update
